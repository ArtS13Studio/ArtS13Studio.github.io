# Сайт ArtS13Studio

Инструкция для Сани (NicopoloL) по устройству и редактированию сайта.

## Главное

Сайт статический: здесь нет сборщика, базы данных и панели администратора. Страницы состоят из обычных HTML, CSS и JavaScript и публикуются через GitHub Pages.

- Сайт: https://arts13studio.github.io/
- Репозиторий: https://github.com/ArtS13Studio/ArtS13Studio.github.io
- Основная ветка: `main`
- Публикация: автоматически после `git push origin main`
- Обновление обычно появляется на сайте через 1–2 минуты.

## Структура

```text
index.html                 главная страница
music/index.html           вся музыка и альбомы

```

В HTML и JavaScript добавлены русские комментарии с названиями основных блоков.

## Как запустить локально

Открыть терминал в папке репозитория и выполнить:

```powershell
python -m http.server 3000
```

Затем открыть `http://localhost:3000/`.

Не открывать HTML двойным щелчком: относительные пути и аудиоплеер надёжнее проверять через локальный сервер.

## Обычный порядок работы

```powershell
git pull origin main
git status
# внести изменения и проверить сайт локально
git add путь-к-изменённому-файлу
git commit -m "Краткое описание изменения"
git push origin main
```

Перед началом всегда делать `git pull`, чтобы не перезаписать чужие изменения. Не использовать `git add .`, если в папке есть временные или исходные файлы.

## Как добавить трек

1. Оптимизированный MP3 положить в `assets/audio/`.
2. Обложку положить в `assets/music/`.
3. Добавить карточку в нужный альбом в `music/index.html`.
4. Добавить трек в массив `tracks` в `assets/player.js`.
5. Значение `data-track-index` карточки должно совпадать с номером трека в массиве `tracks`, начиная с нуля.
6. Проверить Play/Pause, следующий и предыдущий трек, повтор одного и воспроизведение подряд.

Главная страница содержит только три ознакомительных трека. Полная библиотека находится в `music/index.html`.

## Как добавить клип

Большие видеофайлы не хранить в GitHub. Загружать ролик на YouTube или VK Видео, затем вставлять адаптивный `iframe` в `video/index.html`.

Для YouTube используется адрес вида:

```html
https://www.youtube-nocookie.com/embed/VIDEO_ID?rel=0
```

После добавления нового клипа обновить ссылку или превью на главной странице.

## Как добавить одежду

1. Оптимизированное изображение WebP положить в `assets/clothing/`.
2. Добавить карточку в `clothing/index.html`.
3. Если вещь должна появиться на главной, заменить одну из трёх карточек в блоке `clothing-preview-section` файла `index.html`.

На сайте пока нет цен, корзины и оплаты. Это каталог и архив проекта.

### Лукбук, фильтры и галерея одежды

В `clothing/index.html` есть большой баннер с Алексеем и Викторией, кадры разных
вещей, три истории коллекций и общий каталог. Квадратные макеты в карточках
сохраняют формат. В галерее первый кадр вписывается целиком; дополнительные
виды приближают заданные фрагменты оригинала. Только баннер адаптируется к экрану.

- `data-gallery` карточки — уникальный ключ вещи, например `limited-06`.
- `data-category` — категории через пробел: `tshirts`, `hoodies`, `jackets`, `collaborations`.
- Ссылка с `data-open-gallery` открывает галерею по тому же ключу; `data-start` задаёт
  первый кадр (индексация с нуля). Без JavaScript ссылка открывает исходное изображение.
- Дополнительные кадры перечислены в `assets/clothing-gallery.js`. Till Ragnarök
  представляют Алексей и Виктория; Northblood — Лис и Элис; Northern Wind — только Элис.
  Для всех вещей добавлены приближённые детали исходников, для парных макетов —
  отдельно передняя и задняя стороны. Это фрагменты оригиналов, не новые ракурсы съёмки.
  Координаты `view: { x, y, w, h }` заданы долями изображения; первый кадр всегда целый.
- Три истории в `clothing/index.html` содержат крупный кадр и подборку вещей.
  Ссылки подборок используют тот же `data-open-gallery`, отдельные галереи не дублируются.
- Персонажи чередуются между РАЗНЫМИ вещами. Не снимать одну вещь на всех четырёх.
  Образ Лиса — изменённые черты, рыжая борода, без кепки. Точное сходство с исходными
  фото намеренно не сохраняется. Референсы и правила
  интерьера находятся вне публичного репозитория, в `../references/`.
- Фильтр можно передать ссылкой: `clothing/?type=jackets#collection`.
- При обновлении этих файлов меняйте их отдельные параметры `?v=` в HTML.

Галерея поддерживает Escape, стрелки, миниатюры, увеличение и горизонтальные свайпы.
Проверяйте возврат фокуса и прокрутки после закрытия. Мастера генерации и промпты
хранятся вне публикуемого репозитория, в `../output/lookbook-2026-09-05/`.
Актуальная серия записана в `generation-garment-rotation.json`, общий кадр Алексея
и Виктории — в `generation-brand-stories.json`. Старые кадры Лиса из этого файла
не использовать. Ранее утверждённая серия —
в `generation-warm-clean.json`. Исходные PNG и персональные референсы не публикуйте.

## Как обновить коллаборацию

Страница находится в `collaborations/index.html`, изображения — в `assets/collaborations/`.
У Волка ссылки пока показаны как неактивные элементы `<span>`. Когда Алексей передаст точные адреса, заменить нужный `<span>` на `<a href="...">`, добавить `target="_blank" rel="noreferrer"` и убрать подпись `скоро`.
Карточка трека «Разные голоса» ведёт на якорь `#track-raznye-golosa` в музыкальном разделе.

## Стили

Все стили находятся в `assets/styles.css`. Цвета и основные переменные объявлены в `:root` в начале файла.

Основные классы:

- `.hero`, `.directions-section`, `.clothing-preview-section`, `.music-section` — главная;
- `.music-page` — страница музыки;
- `.clothing-page` — страница одежды;
- `.clips-page` — страница клипов;
- `.global-player` — нижний музыкальный плеер;
- медиазапросы `900px` и `560px` — планшет и телефон.

После изменения CSS менять версию в ссылке на файл, например:

```html
<link rel="stylesheet" href="assets/styles.css?v=20260902-change-name" />
```

Это нужно, чтобы браузеры не показывали старую версию из кэша. На внутренних страницах путь начинается с `../assets/`.

## Поиск и статистика

- Яндекс Метрика: счётчик `112156042`.
- Код счётчика стоит на всех публичных страницах.
- Новую страницу нужно добавить в `sitemap.xml`.
- Для публичной страницы обязательно проверить `title`, `description`, canonical и Open Graph.

## Проверка перед публикацией

- Главная, музыка, одежда и клипы открываются без ошибок.
- На телефоне нет горизонтальной прокрутки.
- Изображения имеют `alt`, а декоративные элементы — `aria-hidden="true"`.
- Все внутренние ссылки работают.
- Новый трек выключает предыдущий.
- В репозиторий не попали исходники, временные файлы и тяжёлые видео.
- `git status` содержит только ожидаемые изменения.

## Важные ограничения

- Не менять адреса уже опубликованных файлов без исправления всех ссылок.
- Не удалять `.nojekyll` и файл подтверждения Яндекс Вебмастера.
- Не добавлять пароли, токены и другие секреты в код или историю Git.
- Не публиковать цены, оплату, продажи и юридические данные без отдельного согласования с Алексеем.
- Перед крупной переделкой сохранить текущую рабочую версию отдельным коммитом.
